================================================================================
ЧАСТЬ D. АКУСТИЧЕСКИЕ КОНСТАНТЫ
================================================================================

Скорость звука в мягкой ткани (модель):
  c = 1540 м/с

Длина волны:
  lambda = c / f

  f = 1 МГц  -> lambda ≈ 1,54 мм    half-value depth x1/2 ≈ 30 мм
  f = 3 МГц  -> lambda ≈ 0,513 мм   x1/2 ≈ 10 мм
  f = 10 МГц -> lambda ≈ 0,154 мм   x1/2 ≈ 3,0 мм   (заявление Wellcomet)
  f = 19 МГц -> lambda ≈ 0,081 мм   x1/2 ≈ 1,5 мм   (заявление Wellcomet)

x1/2 для 19 МГц — заявление компании, не независимый стандарт IEC,
который в открытых источниках для этой конкретной головки не верифицирован.

Коэффициент затухания в ткани (степенной закон):
  alpha(f) = alpha0 * (f / 1 МГц)^n
  n ≈ 1,1 … 1,3

Калибровка alpha0 так, чтобы:
  I(x1/2) = I(0) * exp(-2 * alpha * x1/2) = I(0) / 2
  откуда alpha = ln(2) / (2 * x1/2)

  Для 10 МГц при x1/2 = 3 мм:
    alpha_10 ≈ 115 Np/м ≈ 10 дБ/см
  Для 19 МГц при x1/2 = 1,5 мм:
    alpha_19 ≈ 231 Np/м

Это МОДЕЛЬНЫЕ alpha, не измеренный паспорт головки.

Интенсивность по глубине (плоская волна, нормальное падение):
  I(x) = I0 * exp(-2 * alpha * x)

Давление (среднеквадратичное) в воде/ткани:
  p_rms = sqrt(I * Z)
  Z = rho * c
  rho_tissue ≈ 1050 кг/м³
  Z ≈ 1,62 MRayl

Пиковое давление для непрерывной синусоиды:
  p0 = sqrt(2) * p_rms

Механический индекс (справка, не режим HIFU):
  MI = (p_r,0.3 / МПа) / sqrt(f / МГц)

При I = 0,5 Вт/см² и 10 МГц MI низкий (порядок 0,05–0,15).
Кавитационный режим НЕ основной.
Симулятор НЕ должен рисовать пузырьковый HIFU.

Ближняя зона поршня:
  d_eq = sqrt(4 * ERA / pi) ≈ 19,5 мм
  a = d/2 ≈ 9,75 мм
  z_n = a² / lambda
  На 10 МГц: z_n ≈ 62 мм
  Кожа (2–4 мм) целиком в near field.
  Для дозы по глубине достаточно 1D-экспоненты + поршневое среднее по ERA.
  2D-дифракцию добавлять только если нужна карта hot-spot.

ЧАСТЬ E. ПЬЕЗОЭЛЕМЕНТ: ЭЛЕКТРИКА И МЕХАНИКА
================================================================================

E.1. Режим работы

Излучатель — толщинный (thickness-extensional) диск / шайба PZT,
приклеенный к титановому лицу.

Резонанс по толщине:
  f_r ≈ N_t / h
  или f_r ≈ c_p / (2h)

h — толщина керамики, N_t — частотная постоянная.

Оценка для симулятора (НЕ заводской чертёж):
  SKINOVA_10: f_r = 10 МГц, h ≈ 0,20 мм  при c_p ≈ 4000 м/с
  SKINOVA_19: f_r = 19 МГц, h ≈ 0,105 мм

Типичный материал класса: PZT-4 / PZT-8 (силовой, низкий tan delta).
Точная марка НЕИЗВЕСТНА → параметр PIEZO_TYPE.

Диаметр активного диска ограничен лицом Ø ≤ 29 мм.
ERA = 3,0 см² ⇒ эквивалентный диаметр излучателя ≈ 19,5 мм.
Это не обязательно физический диаметр керамики
(может быть меньше + согласующий слой).

E.2. Электрическая модель Butterworth–Van Dyke (BVD) около резонанса

         C0
    o----||----+
               |
              L1
               |
              C1
               |
              R1   (механические + акустические потери + нагрузка)
               |
    o----------+

C0  — зажатая ёмкость
L1 C1 — механический резонанс
R1  = R_m + R_rad(Z_load)

Последовательный резонанс:  f_s = 1 / (2π * sqrt(L1 * C1))
Антирезонанс:              f_p ≈ f_s * sqrt(1 + C1/C0)

Стартовые калибруемые значения:
  C0      = 0,8 … 3,0 нФ
  k_eff²  = C1 / (C0 + C1) ≈ 0,3 … 0,5
  fs      = f0
  Q_m     = 50 … 200 в воздухе, падает до 10–40 в геле

Нагрузка меняет R1:
  воздух: Z_air ≈ 400 Rayl → почти полный холостой ход, P_ac → 0,
          энергия уходит в нагрев керамики
  гель/кожа: Z ≈ 1,5 MRayl → излучение

ЭТО КЛЮЧЕВОЙ МЕХАНИЗМ:
«нет геля → перегрев пьезо / отключение».

E.3. Согласующие слои (acoustic stack)

Цепочка импедансов:
  PZT (Z ≈ 30–35 MRayl)
    → клей
    → титан (Z ≈ 27 MRayl)
    → гель (Z ≈ 1,5 MRayl)
    → кожа (Z ≈ 1,5–1,7 MRayl)

Титан — не классический четвертьволновый трансформатор к воде.
Это износостойкое лицо + теплоотвод + акустический проводник.

Коэффициент прохождения считать через многослойный T-матричный формализм.
Обязательный модуль симулятора: acoustic_stack.

Потери в клее и лице:
  STACK_EFFICIENCY = 0,5 … 0,8  (электроакустический КПД в контакте)

E.4. Электроакустическое преобразование

Мгновенное напряжение на пьезо v(t), ток i(t).
Механическое смещение лица в поршневой модели:
  u(t) ∝ k33 * v(t)

Скорость поверхности: v_n = du/dt

Излучаемая интенсивность у поверхности
(поршень в импедансе нагрузки):
  I0 = 0,5 * Re{Z_load} * |v_n|²

Ограничение регулятора:
  I_SATA ≤ 0,5 Вт/см²

SATA = spatial-average temporal-average по ERA за период программы
с учётом duty.

Для импульсного режима 1:N:
  duty_cycle D = Ton / (Ton + Toff)

Интерпретация обозначений Wellcomet:
  cont → D = 1
  1:2  → в УЗ-физиотерапии запись «1:2» чаще значит pulse ratio 1:2,
         то есть D = 1/3
  1:5  → D = 1/6

Симулятор ОБЯЗАН иметь флаг:
  DUTY_INTERPRETATION = RATIO_ON_OFF | ON_OVER_PERIOD

Рекомендуемый default:
  D(1:2) = 1/(1+2) = 0,333
  D(1:5) = 1/(1+5) = 0,167

Тогда:
  I_SATA = I_SAPA * D

Заводской потолок 0,5 Вт/см² относится к SATA
(так указывают терапевтические УЗ).
Если в прошивке ограничивают SAPA — параметр LIMIT_DOMAIN = SATA|SAPA.

Частота повторения импульсов (PRF) НЕ опубликована.
Для домашней Skinova это НЕ LDM-переключение частот.

Параметры:
  PRF_HZ default 100          # 50–1000 Гц типичный терапевтический диапазон
  PULSE_SHAPE = rectangular_burst of carrier f0

Внутри каждого burst — синус частоты f0.

E.5. Оценка смещения и ускорения лица

При I = 0,5 Вт/см² и Z = 1,6 MRayl:
  v_n,rms = sqrt(I / Z) ≈ 0,056 м/с
  u_rms   = v_n,rms / ω ≈ 0,9 нм   (на 10 МГц)
  a_rms   = ω * v_n,rms ≈ 3,5e6 м/с²  (на 10 МГц)

Это наносмещения, не «вибрация как массажёр».
Биоэффект в модели Wellcomet идёт от градиента давления / ускорения,
не от видимой амплитуды.
Порядок ускорения совпадает с учебными таблицами Wellcomet
(тысячи km/s² на 1 Вт/см²; у Skinova интенсивность вдвое ниже).

Учебные таблицы Wellcomet (для 1 Вт/см², НЕ для режима Skinova 0,5 Вт/см²):

  Параметр          1 МГц        3 МГц         10 МГц
  Амплитуда         0,018 мкм    0,006 мкм     0,0018 мкм
  Скорость          0,115 м/с    0,115 м/с     0,115 м/с
  Ускорение         725 км/с²    2175 км/с²    7250 км/с²

Длина волны:
  1 МГц ≈ 1,5 мм
  3 МГц ≈ 0,5 мм
  10 МГц ≈ 0,15 мм

Размер «микромассажной ячейки» ≈ lambda/2:
  10 МГц → ≈ 77 мкм
  19 МГц → ≈ 40 мкм

================================================================================
ЧАСТЬ F. ЭЛЕКТРОНИКА ГОЛОВКИ (ПОВЕДЕНЧЕСКАЯ МОДЕЛЬ)
================================================================================

Открытой принципиальной схемы нет. Симулировать как ниже.

F.1. Питание

  Battery → boost/inverter → HF half-bridge или Class-E / Class-D
           → L-match → piezo

На 10–19 МГц реален:
  - полумост + последовательный L, либо
  - Class-E с катушкой у стока.

Модель драйвера:
  Vdrive_peak = 20 … 80 В     # параметр
  f_drive     = f0
  eta_elec    = 0,7           # КПД инвертора
  P_elec      = P_ac / (STACK_EFFICIENCY * eta_elec)

При P_ac = 1,5 Вт и eta_total = 0,4:
  P_bat ≈ 3,8 Вт в непрерывном режиме на максимуме.
  В режиме 1:2 среднее ≈ 1,3 Вт.
  Это задаёт разряд батареи.

F.2. MCU головки — конечный автомат

Состояния:
  IDLE_DOCKED
  IDLE_UNDOCKED
  PROGRAMMED_WAIT
  RUNNING
  PAUSED_NO_CONTACT      # штатно у 19; у 10 — опциональная эвристика по току
  FAULT_OVERTEMP
  FAULT_MOTION
  FAULT_BATTERY
  FINISHED
  LOCKED_NEEDS_STATION   # арендная логика: программа истекла / счётчик сессий

NVM хранит:
  program_id
  f0
  mode            # CONT, PR_1_2, PR_1_5
  I_set
  t_remaining
  session_counter
  max_sessions    # для rental-модели, default unlimited
  serial

F.3. Регулирование интенсивности

Контур:
  1. Задать I_set программы.
  2. Оценить нагрузку по току драйвера / сдвигу резонанса / КСВ.
  3. Подстроить амплитуду V_drive так, чтобы I_SATA → I_set.
  4. Если нагрузка = воздух: ток мал или резонанс уходит
     → для Skinova 19 стоп;
     → для 10 МГц можно оставить нагрев пьезо (модель риска).

Прокси «контакта»:
  contact = (R1 < R1_air * k_th) AND (P_ac > P_min)

F.4. Датчики Skinova 19

  NTC on piezo or face:
    T_warn = 41 °C
    T_off  = 43 °C
    (пороги — ПАРАМЕТРЫ МОДЕЛИ, не паспорт)

  IMU / accelerometer:
    если дисперсия |a| < EPS дольше 2 с при RUNNING
    → FAULT_MOTION или derate

  Self-monitor:
    если driver_current вне допуска → shutdown

F.5. Тепловая модель головки

Два источника тепла:
  1. потери в PZT: P_piezo = (1 - eta_ea) * P_elec
  2. поглощение в коже — кожа греется, лицо чуть греется обратно

Однокомпонентная RC-модель пьезо+титан:
  C_th * dT/dt = P_piezo - (T - T_amb)/R_th - H_gel * (T - T_skin)

Без геля H_gel → 0 → быстрый рост T.

================================================================================
ЧАСТЬ G. ПРОГРАММЫ
================================================================================

Общий цикл любой программы:

  t = 0
  while t < T_prog and state == RUNNING:
      emit carrier f0 with duty D(program)
      move_check()
      temp_check()
      contact_check()
      t += dt
  stop_output()
  state = FINISHED

G.4. Протокол применения (открытые инструкции)

Подготовка:
  очистить кожу;
  тонкий слой УЗ-геля или совместимой сыворотки с хорошим акустическим контактом.

Активация:
  включить рукоятку или снять её с зарядной станции.
  На 19: выбрать одну из 10 программ.

Проведение:
  водить сонотродом медленно и равномерно,
  круговыми или линейными движениями.
  Не держать на точке
  (исключение: в части LDM-протоколов клиник есть semi-static ~10 с —
   это НЕ домашняя инструкция Skinova).

Время:
  10–12 минут в зависимости от программы и зоны.

Кратность:
  дома 1–2 раза в сутки (классическая Skinova);
  салон 2–3 сессии в неделю;
  Skinova 19 — «ежедневно или несколько раз в неделю».

После:
  снять остатки геля, обычный уход.

Симулятор курса:
  объект Course(n_sessions, per_day, gap_days)

Концепция SUPERFRACTIONATION (Wellcomet):
  регулярность важнее разовой интенсивности.
  Поэтому слабый УЗ (0,5 Вт/см²), мелкая глубина, много повторов,
  а не один «жёсткий» сеанс 1 МГц.
  В материалах MED фигурируют примеры вроде 14 процедур 2 раза/день.

Зоны применения домашней версии:
  лицо, шея, декольте.
  MED дополнительно — тело / суставы / болевые зоны по программе.

================================================================================
ЧАСТЬ H. LDM — ЧТО ЭТО И ПОЧЕМУ НЕ ПУТАТЬ СО SKINOVA
================================================================================

LDM® = Local Dynamic Micromassage — патентная идея Wellcomet.

В ОДНОМ сонотроде частоты очень быстро чередуются:
  в описаниях 100–1000 раз в секунду,
  в части брошюр LDM-MED — до 500 Гц переключения.

Комбинации клинических аппаратов:
  LDM 1/3 МГц
  LDM 3/10 МГц
  Triple: 1/3/10 и 3/10/19

Физический смысл, как его формулирует разработчик:
  - абсолютное давление при той же интенсивности почти то же;
  - меняется масштаб градиента давления
    (размер «микромассажной ячейки»):
    с ~0,75 мм на 1 МГц до ~0,075 мм на 10 МГц;
  - возникает пульсация градиентов, которой нет у моночастоты;
  - быстрая смена частоты мешает образованию стоячих волн
    у кости / надкостницы.

Домашняя Skinova / Skinova 19 — это в первую очередь
МОНОЧАСТОТА 10 или 19 МГц + импульсные режимы 1:2 / 1:5.

Дистрибьюторы пишут «LDM + 10 МГц».
По открытым спецификациям Wellcomet для Skinova НЕТ заявленного
dual-frequency switching 100–1000 Гц внутри домашней головки.
Путать домашнюю Skinova с LDM-MED Triple технически неверно.

Skinova Pro — клиника:
  triple-волна 1+3+10 МГц на LDM-MED,
  импульсы длительностью порядка 1–20 мс,
  врач задаёт набор частот и скорость смены.

Отдельный модуль, если нужен LDM:

  LDM_WAVE:
    pair = (fA, fB)     # (3e6, 10e6) или (1e6, 3e6) или triple
    f_switch = 100 … 1000 Hz
    each slot: N cycles of fA then N cycles of fB
    pressure amplitude ~ const
    gradient scale ~ lambda/2 changes

НЕ подставлять это в SKINOVA_10 / SKINOVA_19 по умолчанию.

Разработчик метода в русскоязычных материалах — Илья Кругликов (Wellcomet).

================================================================================
ЧАСТЬ I. ЗАЯВЛЕННЫЙ БИОЭФФЕКТ (ОТДЕЛЬНО ОТ ФИЗИКИ)
================================================================================

Wellcomet связывает высокие частоты / LDM с регуляцией внеклеточного матрикса:
  - снижение активности MMP (матриксные металлопротеиназы, в т.ч. коллагеназы);
  - индукция HSP (heat shock proteins);
  - модуляция гиалуронана / GAG;
  - влияние на фибробласты и организацию коллагена;
  - для 19 МГц отдельно: воздействие на дермальные адипоциты
    на границе дерма–гиподерма;
  - для Skinova Pro / Triple-LDM дополнительно заявляют регуляцию кавеолина-1.

Это гипотезы и внутрифирменные/партнёрские работы,
не общепринятый механизм уровня «доказано как у лазера с измеренным коагулятом».
Независимых крупных RCT по домашней Skinova в открытой выборке источников нет.

Что из ультразвука не спорно физически:
  - механическая микровибрация ткани;
  - слабый нагрев при 0,5 Вт/см² (терапевтический, не абляционный);
  - улучшение микроциркуляции / диффузии;
  - сонофорез: временное повышение проницаемости рогового слоя
    и лучший занос геля/сыворотки.

«Усиливает косметику» — правдоподобно.
«Перестраивает MMP за один сеанс как препарат» — утверждение производителя.

В физсиме биогипотезу дермальных адипоцитов делать НЕ обязательно.
Достаточно дозы:
  H(x) = integral 2 * alpha * I(x) dt

================================================================================
ЧАСТЬ J. ТКАНЬ: СЛОИ ДЛЯ АКУСТИКИ И ТЕПЛА
================================================================================

Минимальный стек лица:

  слой            толщина     rho      c        alpha0
  гель            0,3 мм      1000     1480     малое
  роговой слой    0,02 мм     1100     1500     высокое
  эпидермис       0,08 мм     1100     1540
  дерма           1,5–2,5 мм  1080     1580
  гиподерма       2–8 мм       900     1450     ниже

На 10 МГц большая часть энергии в эпидермисе + дерме.
На 19 МГц пик ещё ближе к верхней дерме / границе дерма–субкутис.

Биотепловое уравнение Пеннеса:

  rho * C * dT/dt
    = div(k * grad T)
    + 2 * alpha * I(r, t)
    + rho_b * C_b * w_b * (T_b - T)
    + Q_met

При I ≤ 0,5 Вт/см² и движении головки ΔT кожи обычно < 1–2 K.
Симулятор должен показывать рост T только если оператор держит
головку неподвижно или работает без геля.

Доза:
  Dose(x) = integral_0^T  2 * alpha(x) * I(x,t) dt     [Дж/м³]

================================================================================
ЧАСТЬ K. ДВИЖЕНИЕ ОПЕРАТОРА
================================================================================

Поршневое поле вблизи лица почти однородно по ERA,
но стоячие волны и hot-spot появляются при фиксации.

Модель движения default:
  head_position(t) = path_circle(r = 15 мм, v = 20 мм/с)
  или linear_scan

Правило Wellcomet: медленные круговые / линейные движения.

Если скорость < 2 мм/с дольше 3 с → предупреждение;
у модели 19 → FAULT_MOTION.

Контактное давление руки: параметр 0,5–2 Н.
На акустику влияет слабо, на толщину геля — да:
  gel_thickness = gel0 / (1 + k * force)

ЧАСТЬ L. ЧЕГО ДОМАШНЯЯ SKINOVA НЕ ДЕЛАЕТ
================================================================================

  - Нет переключения 1↔3↔10 МГц внутри burst с частотой 100–1000 Гц.
    Это LDM.
  - Нет HIFU-фокуса, нет коагуляции, нет абляции.
  - Нет RF.
  - Нет LED в официальных спеках Skinova
    (если реселлер рисует 630/830 нм — путаница с другими приборами,
     не включать).
  - Нет измерения импеданса кожи как косметического «анализатора».
  - Интенсивность потолка 0,5 Вт/см² — не 1–3 Вт/см²
    физиотерапевтического 1 МГц.

================================================================================
ЧАСТЬ M. ПРОТИВОПОКАЗАНИЯ ИЗ ИНСТРУКЦИИ SKINOVA
================================================================================

Не применять без врачебного контроля / не применять вовсе:

  - злокачественные опухоли или подозрение на них;
  - кардиостимулятор, электронные импланты,
    системы жизнеобеспечения,
    носимая электроника типа ЭКГ;
  - глазное яблоко (bulbus oculi);
  - гонады;
  - область сердца;
  - зоны роста костей у подростков;
  - живот при беременности;
  - тяжёлые нарушения кровотока;
  - открытые повреждения кожи;
  - тяжёлые бактериальные инфекции кожи (acne conglobata);
  - свежие послеоперационные рубцы (< 3 месяцев);
  - тромбоз или подозрение на тромбоз.

Это стандартные УЗ-ограничения, не уникальная особенность Skinova.
Симулятор может иметь флаг contraindication_zone, но не «лечит».

Acne conglobata в инструкции: программа Acne этим пациентам запрещена.
Сильно воспалительная acne papulopustulosa — только под врачом.

================================================================================
ЧАСТЬ O. ЦЕПОЧКА «КАК РАБОТАЕТ ПЬЕЗО» ОДНИМ ПРОХОДОМ
================================================================================

  1. MCU включает HF-драйвер на f0.
  2. Переменное поле E = v / h деформирует домены PZT
     (обратный пьезоэффект).
  3. Толщина диска осциллирует на f_r.
  4. Титановое лицо повторяет скорость v_n.
  5. В геле рождается продольная волна p = Z * v_n.
  6. В ткани интенсивность падает как exp(-2 * alpha * x),
     механическая энергия → тепло и микросмещения порядка нанометров.
  7. Импульсный режим снижает SATA и средний нагрев,
     пиковое давление в on-фазе сохраняется.
  8. MCU считает таймер программы и гасит драйвер.
  9. Станция при постановке в кредл заряжает батарею
     и может перезаписать program_id.
